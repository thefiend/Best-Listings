PacificLight's referral code takes $20 off your electricity bill when you sign up online for a home plan of 24 months or longer. The code is **INMRH6USOW**, and you enter it during the online sign-up. We read the programme terms in November 2026 (PacificLight last updated them on 16 April 2024). Plans shorter than 24 months don't qualify, and you can only use one code per account.

## How to Use the PacificLight Referral Code

1. Go to <a href="https://www.pacificlight.com.sg" rel="sponsored noopener noreferrer">pacificlight.com.sg</a> and start a residential sign-up online.
2. Choose a **24, 36 or 60-month** plan. Anything shorter gets no referral rebate.
3. Enter the 10-character code **INMRH6USOW** in the referral code field.
4. Finish the sign-up. The $20 credit shows up within 90 days of your account moving to PacificLight.

## What the Terms Actually Say

The $20 rebate includes GST and can only be used against electricity charges. It isn't paid out as cash. Both accounts (yours and the referrer's) have to be active, with no overdue payments, when PacificLight pays the credit. If you end the contract early, you lose whatever rebate you haven't used yet.

The terms also rule out stacking the referral rebate with other promotions. If PacificLight is running a sign-up offer with a bigger rebate or a gift, compare the two before you enter the code, because you'll likely get one or the other.

Business premises aren't eligible. The programme only covers homes.

## About PacificLight

PacificLight Energy is a Singapore electricity retailer in the Open Electricity Market. It's backed by PacificLight Power, which runs a gas-fired power plant on Jurong Island. Switching to it doesn't change your physical supply, because SP Group still runs the grid, reads your meter and handles any outages.

Before you commit to a 24-month or longer contract, compare PacificLight's rate with SP Group's regulated tariff. For October to December 2026 the tariff is 31.16 cents/kWh including GST. A fixed rate only saves you money if it's below that, and the tariff changes every quarter.

No. PacificLight allows one referral code per new account.
